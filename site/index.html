FAQ

几个常问的。

这是另一个 AI Agent 吗？

不是。MobileVC 是 DSH Host 插件，所有消息、审批、会话读写都走正在运行的 DSH 的 sessionController。没有第二套 Agent，也没有中转服务器。官网不提供公共实例，MobileVC 只连接你自己部署的 DSH。

需要公网 IP 吗？

局域网可以直接访问。想让手机在外面用，可以用你已有的 HTTPS 反代、隧道或内网穿透；Web Push 只需要 DSH 主机能出站访问 Apple/Google 推送服务。

iPhone 能收通知吗？

iOS 16.4+，把 MobileVC 添加到主屏幕，并从主屏幕图标启动，再在「设置 → 通知」里开启。Safari 标签页里不支持 Web Push。

执行迹里的英文思考链能隐藏吗？

默认就是简洁模式：思考按段分组、工具链中文化、英文原文和工具参数折叠。需要排查时再切「完整」。

和旧版 MobileVC 是什么关系？

旧版 Flutter + Go relay + E2EE 保留在仓库的 legacy/ 目录与 git 历史里；现在默认推荐的是 DSH 原生方案。
