一个视频看懂 MobileVC：把 DeepSeek Harness 装进手机。

它不是另一个 Agent，也不是另一套 relay。MobileVC 是 DSH Host 插件，手机连的是你正在运行的那条 session：同一套会话、同一套状态、同一套运行时。

视频里能看到：
· 真实会话与 SSE 实时流
· 手机审批：允许一次 / 拒绝
· 插话先暂存，再选「立即插话」或「排队」
· 执行迹、后台任务、Web Push 通知
· 官网与安装方式
